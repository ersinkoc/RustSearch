# RustSearch 0.0.1 — Windows x64 alpha

The first portable Windows build includes the Rust CLI and GPUI desktop application. Extract the ZIP to a permanent folder and open **rustsearch-desktop.exe**. The README inside the ZIP explains startup, background indexing, runtime prerequisites, and removal.

## Included

- Automatic accessible-file indexing across ready local fixed drives, editable drive scope, and combined search results.
- Per-user background indexing with live committed deltas, pause/resume/stop controls, optional sign-in startup, and reconnect after closing the window.
- File/folder name search, substring/prefix/exact matching, extension and size filters, largest files, file details, Explorer reveal, and path copying.
- Native Windows caption controls, keyboard navigation, application/file-type icons, and light/dark appearances.
- Native NTFS/USN CLI indexing, persistent snapshots/search caches, incremental updates, and benchmark/resource reports.

## Validation and limits

The Windows release suite passes **56 tests**, including real filesystem notifications, background updates with a disconnected GUI client, pause/resume, authenticated IPC, persisted Unicode directory renames, and unchanged base/cache bytes across deltas. Formatting and strict release Clippy pass. Local GUI acceptance and its exact scope are recorded in [DESKTOP_RESULTS.md](https://github.com/ersinkoc/RustSearch/blob/v0.0.1/docs/DESKTOP_RESULTS.md).

This is a **prerelease**, tested on Windows 11 x64. It is unsigned and has no installer or automatic updater. The GUI imports the Microsoft Visual C++ v14 runtime; the package README links the official x64 download if needed. No clean-machine installation or reboot/sign-in acceptance is claimed.

Initial accessible scans can be slow on large drives; permission skips and notification overflow require visible partial-coverage reporting or reconciliation. A full C:/D:/E: scan was restarted locally, but full-machine coverage and long-duration freshness are not release acceptance claims. Fast NTFS mode requires sufficient volume permissions. Disk-space maps, incremental folder totals, content search, tray/global activation, and full Everything parity remain pending.

An [upstream grid dependency advisory](https://github.com/becheran/grid/security/advisories/GHSA-38c5-483c-4qqp) remains open through the pinned GUI layout dependency. It has no compatible lockfile-only fix in the current GPUI dependency graph. The verification notes describe the dependency path and inspection limits.

The ZIP contains both executables, usage/release notes, build provenance, dependency attributions/license texts, and per-file SHA-256 hashes. A separate **SHA256SUMS.txt** verifies the ZIP download. No local disk indexes, settings, filenames, or raw benchmark metadata are distributed.
