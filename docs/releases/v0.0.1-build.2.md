# RustSearch 0.0.1 - Windows x64, build 2

An updated **desktop alpha** with a per-user PowerShell installer. The application
version remains **0.0.1**; the immutable distribution tag is `v0.0.1-build.2`.
The original `v0.0.1` tag and ZIP are preserved.

## Install

```powershell
Invoke-WebRequest https://github.com/ersinkoc/RustSearch/releases/download/v0.0.1-build.2/install.ps1 -OutFile install.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Release v0.0.1-build.2
```

Optional `-StartWithWindows`, `-DesktopShortcut`, `-NoLaunch`, and offline ZIP
installation are documented in [the installation guide](https://github.com/ersinkoc/RustSearch/blob/v0.0.1-build.2/docs/INSTALL.md).
The installer adds Start menu and Installed apps entries, preserves data and
startup preferences, and uses a permanent per-user installation directory.
Updates verify checksums before worker shutdown and restore the previous
installation if activation fails. Uninstall retains saved settings and indexes.
The ZIP also runs portably after extraction.

## Runtime changes since the original archive

- Retain the loaded catalog during notification recovery; coalesce bounded
  queues instead of repeatedly discarding the source and starting new scans.
- Larger local notification buffers, prompt readiness and cancellation, and
  metadata/rename ordering fixes with stable file identities.
- Reuse saved catalogs and check offline changes in cooperative background
  batches, keeping search available after loading.
- Atomically checkpoint accumulated delta history and cache durable validation
  while retaining the writer lock; base snapshots/search caches remain unchanged.
- Bound folder reconciliation with a small parent-row range cache, reducing
  measured background CPU on the tested C:/D:/E: corpus.

Both GUI and CLI are included and must be updated together. **The original
executables cannot read newer `RSDEL002` delta checkpoints.** The installer
preserves saved data and refuses lower distribution build numbers.

## Verification and limits

The local release gate passes **87 Rust tests**, formatting, strict release
Clippy, and the workspace binary build. Installer acceptance runs under Windows
PowerShell 5.1 and PowerShell 7, including real worker migration and rollback.
Published-package installation results are recorded in the repository separately.

Previous real-drive checks cover more than 22 million records, C:/D:/E: searches
and live updates. The latest observed monitoring windows used about 0.80-0.93%
of total machine CPU and about 1.73-1.77 GiB private memory. These are activity-dependent
measurements, not idle or clean-machine guarantees. See
[background CPU results](https://github.com/ersinkoc/RustSearch/blob/v0.0.1-build.2/docs/BACKGROUND_CPU_RESULTS.md).

The application and scripts remain unsigned. Windows 11 x64 is tested locally;
Direct3D 11 and the Microsoft Visual C++ x64 runtime are required. Clean-machine
GUI, Windows 10, mixed DPI, screen-reader and prolonged unattended operation are
not accepted by this release. Accessible indexing skips protected paths; checking
offline changes after restart can take substantial time on large drives. No
automatic updater, tray icon, global hotkey, content search, folder totals or
disk-space treemap is included. No Everything parity/speed claim is made.

The pinned GPUI layout dependency still includes the
[upstream grid advisory](https://github.com/becheran/grid/security/advisories/GHSA-38c5-483c-4qqp).
Checksums provide integrity, not code signing. The ZIP includes source/toolchain
provenance and third-party license notices; no personal indexes or metadata are
distributed.
